## Introduction
Welcome to the NewsToDay project! This is a simple news feed implementation, is intended for both educational purposes and for gaining experience in working in a team. Below is a detailed README.md file that outlines the project, its features, installation instructions, usage, and an overview of the code.

## Features

- **Onboarding:**
  - Introductory screen with the application, all news in one place, be the first to know last news.

- **Registration Page:**
  - It is possible to register and log in using email and password.

- **Browse Page:**
  - On the Browse screen we receive news about new trends in different categories. News search is implemented, and there is also the possibility of adding news to "Favorites".

- **Detail Page:**
  - The screen displays the article image, the author's name, the title, and the current news. From this screen you can go back, and also save the article to Favorites, or delete it from Favorites by pressing the button responsible for adding/removing again.

- **Categories Page:**
  - This screen is provided to the user after registration in the application. The user is presented with a grid with category options, he can select the categories that interest him most. Depending on the user's interests, a grid with news categories is built on the main screen, and recommendations for the user are also displayed.

- **Bookmarks Page:**
  - The user can manage the articles that he/she has added to Favorites. There he/she can also remove the “Favorites” mark from the article, after which it will be deleted from there.

- **Profile Page:**
  - The user data is displayed: personal photo, name, email, there is also a tab with Terms and Conditions. The ability to exit the personal account has been implemented, when clicked, the user gets to the Onboarding screen.

- **Language:**
  - Localization with the ability to change the application language has been implemented.
